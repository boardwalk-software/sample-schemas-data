# Credits & Licenses

This repository redistributes third-party sample databases for use as demo/onboarding
content. The repo's own MIT license (see `LICENSE`) covers this README and any original
content added here — it does **not** relicense the datasets themselves, which remain
under their own original terms below.

## Chinook

- **Source:** [lerocha/chinook-database](https://github.com/lerocha/chinook-database)
- **License:** MIT License
- **File:** `Chinook_Sqlite.sqlite` (from the official v1.4.5 release)
- A digital media store sample dataset — artists, albums, tracks, invoices, customers.

## Sakila

- **Source:** Originally developed by the MySQL AB documentation team; SQLite port via
  [bradleygrant/sakila-sqlite3](https://github.com/bradleygrant/sakila-sqlite3)
  (conversion credited to jOOQ)
- **License:** New BSD License (see `sakila_LICENSE`)
- **File:** `sakila_master.db`
- A DVD rental store sample dataset — films, actors, customers, rentals, payments.

## Sakila XL

- **Source:** Derived from this repo's own `sakila_master.db` (above) — not a separate
  third-party dataset. Same schema, real Sakila data left untouched; ~3.28M additional
  synthetic rows generated by cycling through the existing real column values (names,
  titles, etc.), scaling `customer`/`film`/`payment`/`rental` the most. No new
  third-party content of any kind is introduced.
- **License:** Same as Sakila above (New BSD License) — a derived work of BSD-licensed
  data carries the same terms, and the added rows are mechanically-generated, not
  independently copyrightable content.
- **File:** `Sakila_XL.sqlite`
- **Generator:** `sakila_xl_generate.sql` in this repo — reproducible from a plain copy
  of `sakila_master.db`; see the script's own header comment for exact usage and the
  scaling rationale.
- **Why it exists:** a deliberately large fixture for exercising import/sync at real
  scale — large enough to meaningfully test network-interruption handling during a long
  download or cloud upload, and to reliably exceed every cloud provider's raw upload
  size ceiling (a live test case for CLAUDE.md #153/#154's chunked-upload work). Not
  yet wired into RacerX's own "Examples" menu — see that note before adding it there.

## Why these two

Both are well-known, cleanly-licensed relational sample datasets, chosen as an
alternative to the classic Northwind database specifically because their licensing
chains are unambiguous and traceable back to an authoritative source.
